# ส่งมอบ 17 ก.ย. — โครงสร้าง 171 สำหรับ Velin

> **ยกเลิกแล้วเรื่องราคา:** วันที่ 18 ก.ย. เจ้าของให้กลับมาแสดงราคา ส่วนที่เขียนว่า "ไม่มีราคา" ในไฟล์นี้ไม่ใช้แล้ว ส่วนวิธีเพิ่มภาพยังใช้ได้

- ใช้ 7 รูปแบบโชว์และภาพจาก 171 ตามที่เจ้าของระบุ ไม่แก้โปรเจกต์ต้นทาง
- รักษาโครงสร้างล่าสุด content + photos + src → public ที่พบใน workspace
- 19 หน้าใน sitemap รวมหน้าโชว์และหน้าประเภทงาน รองรับการค้นหาและแชร์แต่ละหน้า
- ไม่มีราคาใน UI, finder, shortlist, ข้อความสำหรับ LINE, metadata หรือ schema
- ปรับหน้ารวมโชว์ 3 คอลัมน์บนจอใหญ่ และภาพเต็มการ์ดบนมือถือ

## เพิ่มภาพ
เปิด เปิดจัดการภาพ.cmd หรือ python tools/media_server.py แล้วไป http://127.0.0.1:4323/__media/

1. เลือกประเภทโชว์
2. เลือกภาพปกหรือแกลเลอรี
3. เลือก JPG/PNG/WebP ไม่เกินภาพละ 12 MB แกลเลอรีได้ครั้งละ 20 ภาพ
4. ใส่คำอธิบายภาพ แล้วบันทึก

รูปเข้า photos/shows/<slug>/ พร้อมแปลง WebP และสร้างเว็บใหม่ในเครื่อง ภาพต้นฉบับและปกเก่าเก็บใน uploads/<slug>/ ไม่ commit/push/deploy อัตโนมัติ

## ข้อจำกัดที่ตรงกับการทำงานจริง
- ภาพจากคลังเป็นตัวอย่างรูปแบบการแสดง ไม่ใช่ทุกภาพเป็น Velin บางรูปมีโลโก้จากงานเดิม
- ข้อความและลิงก์เป็น HTML จริง ส่วน finder/shortlist/ฟอร์มเป็นฟังก์ชัน JavaScript
- ฟอร์มเตรียมข้อความให้ลูกค้าคัดลอกไปส่ง LINE เอง ไม่มีระบบรับคำขอหลังบ้าน
- SEO วางรากฐานหน้าแยก canonical sitemap breadcrumbs และ schema แล้ว แต่ไม่รับประกันอันดับค้นหา
- เปลี่ยนโดเมนใน content/site.json -> url แล้ว build ใหม่เมื่อมีโดเมนจริง
- การเผยแพร่ทำเมื่อเจ้าของสั่งเท่านั้น
