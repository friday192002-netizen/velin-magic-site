# วิธีเพิ่มหรือเปลี่ยนรูป

วางไฟล์รูปต้นฉบับไว้ที่นี่ได้เลย (.jpg .png .webp ขนาดไหนก็ได้)
ระบบจะย่อและแปลงเป็น WebP หลายขนาดให้เองตอนสร้างเว็บ

## รูปของแต่ละโชว์

```
photos/shows/
  opening/    มายากลเปิดตัว
  closeup/    มายากลโคลสอัพ
  stage/      มายากลเวที
  bubble/     บับเบิ้ลโชว์
  juggling/   จั๊กกลิ้ง
  bozo/       โบโซ่ & ลูกโป่ง
  illusion/   มายากลอิลลูชัน
```

- ไฟล์ชื่อ **`cover`** (เช่น `cover.jpg`) = ภาพปก ใช้บนการ์ดและหัวหน้าโชว์
  ภาพปกควรเป็นแนวนอน และมีคนแสดงอยู่ช่วงกลางภาพ
- ไฟล์อื่นทั้งหมด = แกลเลอรี **เรียงตามชื่อไฟล์** ตั้งชื่อเป็น `01.jpg`, `02.jpg`, … จะคุมลำดับได้ง่าย
- ลบรูปไหนทิ้ง รูปนั้นจะหายจากเว็บในการสร้างครั้งถัดไป

## รูปอื่น ๆ

- `velin/hero-cutout.png` — ภาพ Velin แบบตัดพื้นหลัง (ต้องเป็น PNG พื้นโปร่งใส) ใช้ในหน้าแรก
- `velin/portrait-card.webp` — ภาพไพ่ใช้ในส่วนแนะนำตัว
- `site/opening.webp` — ภาพหน้าปกวิดีโอไฮไลต์

ถ้าเปลี่ยนรูปพวกนี้ ให้ใช้ชื่อไฟล์เดิม

## หลังวางรูปแล้ว

ดับเบิลคลิก **`update-site.cmd`** ที่โฟลเดอร์หลักของโปรเจค
เว็บจะถูกสร้างใหม่และเปิดตัวอย่างในเบราว์เซอร์ให้ดู
พอใจแล้วค่อยให้ AI ช่วย commit และ push เพื่อขึ้นเว็บจริง
