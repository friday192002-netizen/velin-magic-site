# Velin Magic

เว็บไซต์ศิลปินและการแสดงมายากล 7 รูปแบบ พร้อมหน้าแยกตามประเภทงาน **แสดงราคาทุกรูปแบบ** (แก้ราคาที่ content/shows.json)

## เพิ่มรูปจากเครื่อง
ดับเบิลคลิก **เปิดจัดการภาพ.cmd** แล้วเลือกโชว์ → ภาพปกหรือแกลเลอรี → เลือกรูป → บันทึก

ระบบแปลงภาพเป็น WebP และสร้างพรีวิวใหม่ ภาพต้นฉบับและปกเดิมเก็บใน uploads/ เว็บจริงจะเปลี่ยนเมื่อสั่ง Deploy เท่านั้น

หรือวางรูปใน photos/shows/<ชื่อโชว์>/ แล้วดับเบิลคลิก update-site.cmd

| สิ่งที่แก้ | ตำแหน่ง |
| --- | --- |
| ข้อความและรายละเอียดโชว์ | content/shows.json |
| เบอร์โทร LINE และโซเชียล | content/site.json |
| ประเภทงานและลำดับโชว์ | content/occasions.json |
| คำถามที่พบบ่อย | content/faq.json |
| รูปแบบหน้าเว็บ | src/templates/ |
| สี ฟอนต์ การจัดวาง | src/css/site.css |

อย่าแก้ public/ โดยตรง เพราะเป็นผลลัพธ์ที่สร้างจากข้อมูลด้านบน
